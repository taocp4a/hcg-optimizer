ez-CGER 이미지 최적화

페이지 전환 지연을 줄이도록 이미지 용량을 줄이고, 전체 페이지를 PDF로 출력합니다.

사용 방법

  1. hcg 파일과 같은 이름의 폴더를 함께 선택하십시오.
  2. 마우스 오른쪽 버튼 → [ZIP 파일로 압축]을 누르십시오.
  3. 만들어진 zip 파일을 아래에 놓으십시오.

페이지 PDF만 필요하면 hcg 파일 하나만 놓아도 됩니다.
