ez-CGER 이미지 최적화

페이지 전환 지연을 줄이도록 이미지 용량을 줄이고, 전체 페이지를 PDF로 출력합니다.

사용 방법

  1. hcg 파일과 같은 이름의 이미지 폴더를 함께 선택하십시오. (예: 주일예배.hcg와 주일예배 폴더)
  2. 선택한 항목에서 마우스 오른쪽 버튼을 누르고 [압축(ZIP) 폴더] 또는 [ZIP 파일로 압축]을 선택하십시오.
  3. 만들어진 zip 파일을 아래 영역에 놓으십시오.

페이지 PDF만 필요하면 hcg 파일 하나만 놓아도 됩니다.

파일은 외부로 전송되지 않으며 이 컴퓨터에서만 처리됩니다.
